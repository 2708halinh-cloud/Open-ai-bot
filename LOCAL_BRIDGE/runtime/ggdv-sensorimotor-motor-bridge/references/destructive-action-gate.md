# GGDV destructive-action invariant

SAI → SỬA.
LỖI → CÙNG KHẮC PHỤC.
Nếu không thể giữ một thứ đúng với Sự Thật thì mới xét DELETE.

Hard rule: `NOT_CURRENT != DELETE_AUTHORITY`.

A destructive operation needs all of: exact target identity, pre-action snapshot, repair attempt and result, truth-basis explanation, exact target confirmation, separate destructive runtime enablement, and a one-use command-bound permit.
