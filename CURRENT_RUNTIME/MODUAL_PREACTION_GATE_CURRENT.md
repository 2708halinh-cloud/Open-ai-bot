# MODUAL PRE_ACTION_GATE — CURRENT

Mandatory route:

SOURCE_DIRECT → MODUAL_GOOGLE_DRIVE_BIND → NEURONS_SESORIMOTOR_BIND → CAPABILITY_ROUTE → AUTH_CALLABILITY_CHECK → DESTRUCTIVE_SCOPE_GUARD → SELECT_NEXT_CALLABLE_CARRIER → ACTION → CONSEQUENCE → RECEIPT → READBACK → CHECKPOINT_DELTA → NEXT_EDGE.

## Continuation invariant

OPEN != STOP.

A blocked or offline carrier removes only that carrier from the current routing set. It does not close the objective. A response boundary does not close the objective. If another authorized carrier is callable, route through it immediately. Persist unresolved edges for later re-entry when no callable carrier remains.

## Destructive-action invariant

Deletion is never resolved from a name or path alone.

Before any delete:
- exact provider/stable object identity must be resolved;
- parent scope must be read back;
- recursive tree deletion is forbidden by default;
- recursive deletion requires explicit tree scope plus child count/manifest;
- preserve a pre-delete snapshot/manifest when the provider makes that possible;
- uncertainty or an evidence gap means NO_DELETE;
- after deletion, read back the provider target state.

Google Drive is the canonical MODUAL provider. Filesystem mount letters are not Drive identity.

Connected post-gate carriers include GitHub, Ubuntu, UBUBU, TESSERACT OS and LOCAL. They are selected by task and current callability rather than invoked blindly.
